Opportunity@Work organizational knowledge skill — a comprehensive reference covering the mission, programs, research, technology platforms, and data of [Opportunity@Work](https://opportunityatwork.org), the nonprofit social enterprise advancing skills-first hiring for 70+ million workers Skilled Through Alternative Routes (STARs).

- **`opportunity-at-work.skill.md`** — Full skill file mapping the organization's mission, STARs framework, Paper Ceiling research, reports (Reach for the STARs, Navigating with the STARs, Rise with the STARs, State of the Paper Ceiling), programs (Tear the Paper Ceiling, Powering STAR Breakthroughs, Public Sector Hub), technology platforms (STARSight, STARSight Connect), partnerships, funding, and key metrics.
