# StratAI: Executive GenAI Training

A Streamlit-based interactive training platform designed to help executives understand Generative AI fundamentals, industry-specific implications, and strategic decision-making.

## Features

- **Module 1: GenAI Fundamentals** - Learn the basics of discriminative vs generative AI and key terminology
- **Module 2: Industry Impact** - Explore ROI opportunities, risks, and real-world case studies tailored to your industry
- **Module 3: Strategic Simulator** - Practice decision-making with realistic AI governance scenarios

### Supported Industries
- Finance
- Healthcare
- Retail
- Manufacturing

## Installation

```bash
pip install -r requirements.txt
```

## Usage

```bash
streamlit run app.py
```
