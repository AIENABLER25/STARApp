# Dr. Byron Auguste Archive

A comprehensive digital archive centralizing 20+ years of Dr. Byron Auguste's research, media appearances, speaking engagements, and initiatives in workforce development and economic opportunity.

## About Dr. Byron Auguste

Dr. Byron Auguste is the CEO and Co-founder of **Opportunity@Work**, a nonprofit social enterprise focused on expanding career opportunities for all Americans. With a distinguished career spanning McKinsey & Company (where he was the first Black senior partner) and the Obama White House, Dr. Auguste has been a pioneering voice in workforce development and economic mobility.

## Features

### Content Categories

- **Biography & Timeline**: Educational background, career highlights, awards, and chronological timeline
- **Research & Publications**: McKinsey Global Institute reports, books, and research papers (2009-2024)
- **Media Appearances**: Television, print, radio, and podcast features
- **Speaking Engagements**: Keynotes and presentations at major institutions
- **Key Initiatives**: STARs movement, "Tear the Paper Ceiling" campaign, and STAR Mobility Compass

### Functionality

- **Search**: Full-text search across all content
- **Tag Filtering**: Filter publications and initiatives by topic tags
- **Category Navigation**: Browse by content type
- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile
- **External Links**: Direct links to original sources when available

## Key Initiatives Documented

### STARs (Skilled Through Alternative Routes)
A national movement recognizing 70+ million U.S. workers who developed skills through alternative routes rather than bachelor's degrees.

### Tear the Paper Ceiling Campaign
National campaign that achieved 4+ billion impressions to eliminate degree requirements blocking qualified workers.

### STAR Mobility Compass
Data-driven framework identifying career pathways for STARs, projected to help 10 million workers access higher-wage jobs by 2030.

## Deployment to Production

### Quick Deploy

Use the deployment script:

```bash
./deploy.sh
```

Or deploy manually:

**Option 1: Vercel (Recommended)**
```bash
npm install -g vercel
vercel --prod
```

**Option 2: Netlify**
```bash
npm install -g netlify-cli
netlify deploy --prod
```

**Option 3: GitHub Pages**
See [DEPLOYMENT.md](./DEPLOYMENT.md) for detailed instructions.

### Deployment Files

- `vercel.json` - Vercel configuration
- `netlify.toml` - Netlify configuration
- `DEPLOYMENT.md` - Comprehensive deployment guide
- `deploy.sh` - Automated deployment script

For detailed deployment instructions including custom domains, environment variables, and troubleshooting, see [DEPLOYMENT.md](./DEPLOYMENT.md).
